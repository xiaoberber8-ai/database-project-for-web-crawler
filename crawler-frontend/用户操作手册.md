# 爬虫数据管理系统 - 用户操作手册

## 一、系统概述

本系统是一个完整的网络爬虫数据管理平台，包含前端可视化界面和后端爬虫引擎。用户可以通过浏览器进行爬虫策略配置、数据抓取、数据管理和内容检索。

### 系统架构

| 组件 | 端口 | 说明 |
|------|------|------|
| 前端界面 | 3000 | Vue 3 + Element Plus，用户操作入口 |
| 后端 API | 8000 | FastAPI，爬虫控制和策略管理 |
| 数据代理 | 8002 | 数据查询服务（webpage/content/image） |
| MySQL 数据库 | 3306 | 数据存储 |

## 二、启动步骤

### 前提条件
- Python 3.8+ 已安装
- Node.js 18+ 已安装
- MySQL 服务已运行
- 后端依赖已安装：`fastapi, uvicorn, sqlalchemy, pymysql, requests, beautifulsoup4, lxml, pydantic`
- 前端依赖已安装：在 `crawler-frontend` 目录执行 `npm install`

### 启动顺序（必须按顺序）

**第一步：启动后端爬虫服务**
```bash
cd /home/xiaoberber/web_crawler/database-project-for-web-crawler/爬虫数据库系统
DATABASE_URL="mysql+pymysql://root:zhouwanyi1222@172.31.224.1:3306/crawler_db?charset=utf8mb4" python3 CRAWLER_NEW.py
```
> 看到 `Uvicorn running on http://0.0.0.0:8000` 表示成功

**第二步：启动数据查询代理**
```bash
cd /home/xiaoberber/web_crawler/database-project-for-web-crawler/crawler-frontend
DB_HOST=172.31.224.1 DB_PASSWORD=zhouwanyi1222 python3 data_proxy.py
```
> 看到 `Uvicorn running on http://0.0.0.0:8002` 表示成功

**第三步：启动前端界面**
```bash
cd /home/xiaoberber/web_crawler/database-project-for-web-crawler/crawler-frontend
npx vite --host 0.0.0.0
```
> 看到 `Local: http://localhost:3000/` 表示成功

**第四步：打开浏览器访问**
- 本机访问：http://localhost:3000

## 三、登录系统

### 登录页面

进入 http://localhost:3000 后首先看到登录页面。

**操作方法：**
1. 在「用户名」输入框输入任意用户名（如 `admin`）
2. 在「密码」输入框输入任意密码（如 `admin123`）
3. 点击「登录」按钮

**注意：**
- 用户名和密码不能为空即可通过验证
- 登录成功后会自动跳转到仪表盘页面
- 登录信息保存在浏览器本地存储中，关闭浏览器不会自动退出

**退出登录：**
点击右上角用户名旁边的下拉菜单，选择「退出登录」

## 四、功能模块详解

### 4.1 仪表盘（Dashboard）

**位置：** 左侧菜单 → 仪表盘

**显示内容：**

| 卡片 | 说明 |
|------|------|
| 爬取网页数 | 所有已抓取的网页总数 |
| 文本内容数 | 提取的文本/文章数量 |
| 图片数量 | 下载的图片总数 |
| 任务总数 | 执行过的任务记录总数 |

**其他区域：**
- **爬虫运行状态**：显示当前爬虫是否正在运行、是否暂停、是否已停止。绿色圆点闪烁表示运行中
- **最近任务列表**：最近 5 条任务记录，显示 ID、策略ID、状态、抓取条目、开始时间
- **策略概览**：所有爬虫策略的名称和启用/禁用状态

**状态标签颜色说明：**
- 绿色（success）：已完成 / 运行中 / 启用
- 黄色（warning）：运行中（任务状态）
- 橙色（info）：等待中 / 禁用
- 红色（danger）：失败

---

### 4.2 爬虫管理（Crawler）

**位置：** 左侧菜单 → 爬虫管理

这是系统的核心功能模块，包含以下四个区域：

#### 4.2.1 状态监控区（顶部四张卡片）

实时显示：
- **爬虫状态**：运行中 / 未运行
- **暂停状态**：已暂停 / 正常
- **停止状态**：已停止 / 正常
- **策略数量**：当前策略总数

#### 4.2.2 爬虫控制区

**操作步骤：**

1. **选择策略**：从下拉框中选择要执行的爬虫策略
2. **点击控制按钮**：

| 按钮 | 功能 | 使用场景 |
|------|------|----------|
| 启动 | 开始执行选中的策略 | 选择策略后点击 |
| 暂停 | 暂停当前运行的爬虫 | 爬虫运行中时可用 |
| 恢复 | 恢复被暂停的爬虫 | 爬虫暂停时可用 |
| 停止 | 完全停止爬虫 | 爬虫运行或暂停时可用 |
| 刷新状态 | 手动刷新爬虫状态 | 随时可用 |

**注意事项：**
- 同一时间只能运行一个爬虫任务（单线程设计）
- 如果爬虫正在运行，「启动」按钮会变灰不可点
- 点击「刷新状态」可查看最新状态（系统也会每 3 秒自动刷新）

#### 4.2.3 策略管理表格

显示所有已创建的爬虫策略，包含以下列：

| 列名 | 说明 |
|------|------|
| ID | 策略唯一编号 |
| 策略名称 | 自定义的名称 |
| 目标URL | 要爬取的主站地址 |
| 状态 | enabled=启用 / disabled=禁用 |
| 频率 | manual=手动 / daily=每天 / weekly=每周 |
| 深度 | 爬取链接深度（建议 1-2） |
| 创建时间 | 策略创建的时间 |
| 操作 | 编辑 / 删除 |

##### 新建策略

1. 点击右上角「新建策略」按钮
2. 弹出对话框，填写以下信息：

**基本信息：**
- **策略名称**（必填）：给爬虫起个名字，如「新浪新闻爬虫」
- **目标URL**（必填）：要爬取的网站地址

**爬取规则：**
- **爬取深度**：1 表示只抓起始页，2 表示从起始页链接再深入一层。建议不超过 3
- **允许域名**：限制只爬取哪些域名下的页面。可添加多个域名
- **起始URL**：实际开始爬取的 URL 列表。可添加多个

**文本规则：**
- **标题选择器**：CSS 选择器，用于提取标题。常用值：`h1`、`.title`、`#title`
- **正文选择器**：CSS 选择器，用于提取正文。常用值：`.article`、`.content`、`body`

**图片规则：**
- **图片选择器**：CSS 选择器，用于定位图片元素。通常为 `img`
- **下载图片**：开关，是否自动下载图片到本地
- **图片目录**：图片保存路径，默认 `./images`

**请求设置：**
- **超时时间**：每次请求的超时秒数，默认 30 秒
- **请求频率**：每秒最多请求次数，建议设为 1（避免被封）

**其他设置：**
- **策略状态**：启用 / 禁用
- **执行频率**：手动 / 每天 / 每周

3. 填写完成后点击「创建」按钮

##### 编辑策略

1. 在策略列表中找到目标行
2. 点击「编辑」按钮
3. 在弹出的对话框中修改参数
4. 点击「保存」按钮

##### 删除策略

1. 在策略列表中找到目标行
2. 点击「删除」按钮
3. 在确认弹窗中点击「确定」

> 注意：删除策略不会删除该策略已经产生的爬取数据

#### 4.2.4 任务记录表格

显示所有历史任务，包含以下列：

| 列名 | 说明 |
|------|------|
| ID | 任务唯一编号 |
| 策略ID | 对应的策略 ID |
| 状态 | running=运行中 / completed=已完成 / pending=等待中 / failed=失败 |
| 抓取条目 | 本次任务抓取到的内容条目数 |
| 开始时间 | 任务开始执行的时间 |
| 结束时间 | 任务结束的时间 |
| 错误信息 | 失败时的错误详情 |

### 4.4 内容检索（Search）

**位置：** 左侧菜单 → 内容检索

提供高级搜索功能，支持多条件组合查询。

#### 搜索条件

| 条件 | 说明 | 示例 |
|------|------|------|
| 关键字 | 同时搜索标题和正文内容 | `习近平`、`抗战` |
| 发布者 | 搜索作者/发布者字段 | `新华社` |
| 时间范围 | 按发布日期筛选 | 选择起止日期 |
| 域名 | 按来源网站域名筛选 | `sina.com.cn` |

#### 操作步骤

1. 输入一个或多个搜索条件
2. 点击「搜索」按钮
3. 查看搜索结果（关键字会被高亮标记）
4. 点击「重置」清空所有条件

#### 搜索结果

- 显示匹配的总条数和搜索耗时
- 结果以表格形式展示，包含标题、正文预览、发布者、发布时间
- 匹配的关键字会用黄色背景高亮显示
- 点击「查看」可看完整内容

## 五、常见问题排查

### Q1：打开前端页面空白或报错
**原因：** 后端或数据代理未启动
**解决：** 确认三个服务都已启动（端口 8000、8002、3000）

### Q2：登录后页面没有数据
**原因：** 还没有执行过爬虫任务
**解决：** 进入「爬虫管理」→ 新建策略 → 启动爬虫

### Q3：新建策略后启动爬虫没反应
**原因：** 可能已有爬虫在运行
**解决：** 查看顶部状态卡片，如果显示「运行中」，先点击「停止」再重新启动

### Q4：数据管理页面报错
**原因：** 数据代理服务未启动
**解决：** 确认端口 8002 的 data_proxy.py 正在运行

### Q5：图片无法显示
**原因：** 图片保存在服务器本地文件系统中
**解决：** 图片存储在后端的 `./images` 目录下，需要单独配置静态文件服务才能在浏览器直接访问

### Q6：爬取速度很慢
**原因：** rate_limit 设置过低或目标网站响应慢
**解决：** 编辑策略适当增大超时时间和请求频率；depth 不宜设置过大

### Q7：端口被占用
**解决：**
```bash
# 查看占用端口的进程
ss -tlnp | grep 端口号

# 杀掉进程
kill -9 进程PID
```
